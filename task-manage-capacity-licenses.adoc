= 管理Cloud Volumes ONTAP基於容量的許可
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: https://docs.netapp.com/us-en/console-licenses-subscriptions/media/


[role="lead lead"]
從NetApp Console管理基於容量的許可證，以確保您的NetApp帳戶具有足夠的容量用於您的Cloud Volumes ONTAP系統。

_容量型授權_ 可讓您按每 TiB 容量為 Cloud Volumes ONTAP 付費。

您可以從 NetApp Console 管理容量型 Cloud Volumes ONTAP 授權。


NOTE: 雖然 Console 中代管的產品和服務的實際使用量和計量始終以 GiB 和 TiB 為單位計算，但 GB/GiB 和 TB/TiB 這兩個術語可以互換使用。這一點體現在雲端市場清單、報價、清單描述和其他支援文件中。

https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/concept-licensing.html["深入瞭解 Cloud Volumes ONTAP 授權"^]。



[[how-licenses-are-added-to-netapp-console]]
== 如何將授權新增至 NetApp Console

向 NetApp 銷售代表購買授權後，NetApp 將會傳送一封包含序號和其他授權詳細資訊的電子郵件給您。

同時，Console 會自動查詢 NetApp 的授權服務，以取得與您的 NetApp 支援網站帳戶關聯的授權詳細資訊。如果沒有錯誤，則會新增授權。

如果 Console 無法新增授權，您需要手動新增。例如，如果 Console 代理程式安裝在無法存取網際網路的位置，您需要自行新增授權 https://docs.netapp.com/us-en/bluexp-digital-wallet/task-manage-data-services-licenses.html#add-a-license["了解如何將購買的授權新增至您的帳戶"^]。



[[view-the-consumed-capacity-in-your-account]]
== 檢視您帳戶中已使用的容量

Console 會顯示您帳戶中已使用容量的總計，以及依授權套件劃分的已使用容量。這有助於您了解收費方式，以及是否需要購買額外容量。

.步驟
. 從左側導覽窗格中，選取 *Administration > Licenses and subscriptions*。
. 在「概覽」標籤上，Cloud Volumes ONTAP 磁貼會顯示為您的帳戶佈建的目前容量。
+
image:screenshot_cvo_licensing_card.png["width=300 顯示 Cloud Volumes ONTAP 授權和訂閱容量總結的快照。"]

+
** 「直接授權」是指您 NetApp 帳戶中所有 Cloud Volumes ONTAP 系統的總配置容量。計費是基於每個 Volume 的配置大小，與 Volume 內的本機空間、已使用空間、儲存空間或有效空間無關。
** _年度合約_ 是指您從 NetApp 購買的總授權容量（自帶授權 (BYOL) 或市場合約）。
** _PAYGO_ 是使用雲端市場訂閱所佈建的總容量。只有當已使用容量超過授權容量，或 Console 中沒有可用的 BYOL 授權時，才會透過 PAYGO 計費。


. 選擇 *View* 以查看每個授權方案的已使用容量。
. 選取 *Licenses* 索引標籤，查看您所購買的每個套件授權的詳細資訊。
+
為了更好地理解 Essentials 套件中顯示的容量，您應該熟悉收費方式的運作原理 https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/concept-licensing.html#notes-about-charging["了解 Essentials 套件的收費方式"^]。

. 選取「*訂閱*」索引標籤，即可查看依授權消費模式的已使用容量。此索引標籤包含 PAYGO 及年度合約授權。
+
您只會看到與您目前檢視的組織關聯的訂閱。

. 檢視訂閱資訊時，您可以與表格中的詳細資訊互動。展開某一列即可檢視更多詳細資訊。
+
** 選擇 image:icon-column-selector.png["表格標題末尾的加號圖示"] 以選擇要在表格中顯示的欄。請注意，「期限」和「自動續訂」欄預設不會顯示。「自動續訂」欄僅顯示 Azure 合約的續訂資訊。

+
image:screenshot_licensing.png["「切換到進階檢視」按鈕的快照"]

[[change-charging-methods]]
== 變更收費方式

容量型授權以_套件_的形式提供。建立 Cloud Volumes ONTAP 系統時，您可以根據業務需求從多個授權套件中進行選擇。如果系統建立後需求發生變化，您可以隨時變更套件。例如，您可以從 Essentials 套件變更為 Professional 套件。

https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/concept-licensing.html["深入瞭解容量型授權套件"^]。

.關於此任務
* 更改收費方式不會影響您是透過向 NetApp 購買授權（BYOL）還是透過雲端供應商的市場隨用隨付（PAYGO）訂閱收費。
+
Console 一律會優先嘗試針對授權進行計費。如果授權不可用，則會針對市場訂閱進行計費。您無需將 BYOL 訂閱轉換為市場訂閱，反之亦然。

* 如果您從雲端供應商的市場獲得了私人報價或合約，則變更為合約中未包含的計費方式，將導致按 BYOL（如果您從 NetApp 購買了授權）或 PAYGO 計費。
* 如果您打算透過 AWS 市場中的獨立式 Cloud Volumes ONTAP 訂閱對 Cloud Volumes ONTAP 容量進行計費，則 Cloud Volumes ONTAP 系統必須使用受支援的容量型套件（Essentials 或 Freemium）。Professional 套件不支援獨立式清單，仍將透過 NIS 訂閱進行計費。選擇所需的套件後，請使用 NetApp Console 中的 *Billing preferences* 選擇用於 Cloud Volumes ONTAP 計費的市場訂閱。


.步驟
. 從左側導覽窗格中，選取 *Administration > Licenses and subscriptions*。
. 選擇 *Overview* 標籤。
. 在 Cloud Volumes ONTAP 圖磚上，選取 * 檢視 *。
. 選擇 *Switch to advanced view*。
+
image:screenshot_licensing.png["「切換到舊版檢視」按鈕的螢幕擷取畫面"]

. 向下捲動至「容量型授權」表格，然後選擇「變更計費方式」。
+
image:screenshot-digital-wallet-charging-method-button.png["Console 中 Cloud Volumes ONTAP 頁面的快照，其中「變更計費方式」按鈕位於表格上方。"]

. 在「變更計費方式」彈出視窗中，選擇 Cloud Volumes ONTAP 系統，選擇新的計費方式，然後確認您了解變更套件類型將會影響服務費用。
. 選擇 *Change charging method*。




[[download-usage-reports]]
== 下載使用情況報告

您可以從 Console 下載四份使用量報告。這些使用量報告提供您訂閱的容量詳情，並說明您如何為 Cloud Volumes ONTAP 訂閱中的資源付費。這些可下載的報告記錄了特定時間點的資料，並且可以輕鬆地與他人共享。

image:screenshot-download-usage-report.png["快照顯示 Cloud Volumes ONTAP 容量型授權頁面，並反白顯示使用情況報告按鈕。"]

以下報告可供下載。所示容量值單位為 TiB。

* *High-level usage*：本報告彙整了您帳戶的總容量使用情況，並按計費方式（預購授權與隨用隨付）進行細分。報告包含以下資訊：
+
[cols="1,2"]
|===
| 欄 | 描述 


| 總消耗容量 | 您帳戶中所有 Cloud Volumes ONTAP 系統的總佈建容量。 


| 總預承諾容量 | 您從 NetApp 購買的總授權容量，包括 BYOL 授權和 Marketplace 合約。此值為 BYOL 總容量與 Marketplace 合約總容量的總和。 


| BYOL 總容量 | 您直接從 NetApp 購買的自帶授權 (BYOL) 授權所涵蓋的預承諾容量部分。 


| 市場合約總容量 | 透過雲端服務提供者的市場購買的年度市場合約或私有報價所涵蓋的預承諾容量部分。 


| PAYGO 總容量 | 已消耗容量中未被任何預先承諾授權涵蓋的部分，按隨用隨付（PAYGO）的每小時市場費率計費。 
|===
* *Cloud Volumes ONTAP 套件使用量*：本報告提供的容量細分與高階使用量報告相同，但依授權套件進行組織。報告包含以下資訊：
+
[cols="1,2"]
|===
| 欄 | 描述 


| 總消耗容量 | 此套件在您帳戶中所有 Cloud Volumes ONTAP 系統上的總佈建容量。 


| 總預承諾容量 | 您從 NetApp 購買的此套件的授權總容量，包括 BYOL 授權和 Marketplace 合約。此值為 BYOL 總容量與 Marketplace 合約總容量的總和。 


| BYOL 總容量 | 此套件的預承諾容量部分，由您直接向 NetApp 購買的自帶授權 （BYOL） 授權所涵蓋。 


| 市場合約總容量 | 此套餐中預先承諾的容量部分，由年度市場合約或透過雲端供應商市場購買的私有報價所涵蓋。 


| PAYGO 總容量 | 此套件中已用容量中未涵蓋於任何預先承諾授權的部分，將按隨用隨付（PAYGO）每小時市場費率計費。 
|===
* *Storage VMs usage*：本報告顯示 Cloud Volumes ONTAP 系統和儲存設備虛擬機器 （SVM） 的已計費容量細分。此資訊僅在報告中提供。報告包含以下資訊：
+
[cols="1,2"]
|===
| 欄 | 描述 


| 系統 ID 和名稱 | Cloud Volumes ONTAP 系統的唯一識別碼 （UUID） 和顯示名稱。 


| 雲端 | 系統部署所在的雲端供應商（例如 AWS、Azure 或 Google Cloud）。 


| NetApp 帳戶 ID | 與系統關聯的 NetApp 帳戶識別碼。 


| 系統組態 | 系統的部署組態（例如，單節點或 HA 配對）。 


| SVM 名稱 | Cloud Volumes ONTAP 系統中儲存虛擬機器 （SVM） 的名稱。 


| 已預留容量 | SVM 上佈建的總容量。 


| 計費容量匯總 | SVM 實際計費容量。每個 SVM 都有一個最低計費容量（預設為 4 TiB，但具體數值可能因帳戶而異）。如果 SVM 的已佈建容量等於或低於該最低值，則此值向上取整至最低值；否則，它等於已佈建容量。 


| 市集計費條款 | 相關市場訂閱的計費週期（例如，按小時或按年計費）。 


| Cloud Volumes ONTAP 套件或功能 | 與 SVM 關聯的授權套件或功能（例如，Essentials 或 Professional）。 


| 收費 SaaS Marketplace 訂閱名稱 | 用於計費的市集訂閱名稱。 


| 為 SaaS Marketplace 訂閱 ID 收費 | 用於計費的市場訂閱唯一識別碼。 


| 工作負載類型 | 指示 SVM 的磁碟區是 *Primary*（讀取/寫入），主動用於生產資料，還是 *Secondary*（DP），資料保護目標磁碟區，例如用於備份和複寫的 SnapMirror 複本。 
|===
* *Volume 使用情況*：此報告顯示 Cloud Volumes ONTAP 系統中各 Volume 的已使用容量明細。此資訊在 Console 的任何畫面上均無法取得。其中包含以下資訊：
+
[cols="1,2"]
|===
| 欄 | 描述 


| 系統 ID 和名稱 | 包含該磁碟區的 Cloud Volumes ONTAP 系統的唯一識別碼 （UUID） 和顯示名稱。 


| SVM 名稱 | 包含該磁碟區的儲存虛擬機器 （SVM） 的名稱。 


| 磁碟區 ID | 該磁碟區的唯一識別碼。 


| 磁碟區類型 | 磁碟區的類型（例如，讀寫或資料保護）。 


| Volume 已佈建容量 | 為磁碟區佈建的總容量。 
|===
+

NOTE: 此報告不包含 FlexClone® Volume，因為這類型的 Volume 不會產生費用。



.步驟
. 從左側導覽窗格中，選取 *Administration > Licenses and subscriptions*。
. 在「概覽」標籤上，從 Cloud Volumes ONTAP 圖格中選取「檢視」。
. 選擇 *Usage report*。
+
使用量報告已下載。

. 開啟下載的檔案即可存取報告。

= 在 Azure 中為Cloud Volumes ONTAP啟用高可用性模式
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
為您的 Cloud Volumes ONTAP HA 配對啟用 Microsoft Azure 高可用度（HA）模式，以減少非計畫性容錯移轉時間並支援 NFSv4。此模式可在非計畫性容錯移轉期間為 CIFS 和 NFSv4 用戶端提供 60 秒的恢復時間目標（RTO）。

從 Cloud Volumes ONTAP 9.10.1 版本開始，我們縮短了在 Microsoft Azure 中運作的 Cloud Volumes ONTAP HA 配對的非計畫性容錯移轉時間，並增加了對 NFSv4 的支援。若要讓 Cloud Volumes ONTAP 能夠使用這些增強功能，您需要在 Azure 訂閱中啟用 HA 功能。

.關於此任務
當您需要在 Azure 訂閱上啟用此功能時，NetApp Console 會顯示提示。請注意以下事項：

* 此功能與 ONTAP 搭配使用，可減少 NFS 用戶端在非計畫性容錯移轉期間所觀察到的應用程式停電時間。啟用此功能並不表示您的 Cloud Volumes ONTAP HA 配對的可用度有問題。
* 啟用此 Azure 功能不會毀損 Cloud Volumes ONTAP HA 配對。
* 在您的 Azure 訂閱上啟用此功能不會影響您環境中的其他虛擬機器或相同訂閱內的任何單節點系統。
* 在容錯移轉期間，Cloud Volumes ONTAP 使用內部 Azure 負載平衡器，供服務 CIFS 和 NFS 用戶端的叢集與 SVM 管理 LIF 使用。
* 啟用 HA 模式後，主控台每 12 小時掃描一次系統，以更新內部 Azure 負載平衡器規則。


.步驟
使用 Azure CLI 以具有 _Owner_ 權限的 Azure 使用者身分啟用此功能。

. https://docs.microsoft.com/en-us/azure/cloud-shell/quickstart["從 Azure 入口網站存取 Azure Cloud Shell"^]
. 註冊高可用性模式功能：
+
[source, azurecli]
----
az account set -s AZURE_SUBSCRIPTION_NAME_OR_ID
az feature register --name EnableHighAvailabilityMode --namespace Microsoft.Network
az provider register -n Microsoft.Network
----
. （可選）驗證該功能現在是否已註冊：
+
[source, azurecli]
----
az feature show --name EnableHighAvailabilityMode --namespace Microsoft.Network
----
+
Azure CLI 應傳回類似以下內容的結果：

+
[listing]
----
{
  "id": "/subscriptions/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/providers/Microsoft.Features/providers/Microsoft.Network/features/EnableHighAvailabilityMode",
  "name": "Microsoft.Network/EnableHighAvailabilityMode",
  "properties": {
    "state": "Registered"
  },
  "type": "Microsoft.Features/providers/features"
}
----

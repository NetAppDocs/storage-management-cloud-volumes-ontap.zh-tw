= 在 AWS 中設定 Cloud Volumes ONTAP HA 配對以建立放置群組
:allow-uri-read: 


[role="lead"]
如果放置群組建立失敗，在 AWS 單一可用度區（AZ）中的 Cloud Volumes ONTAP 高可用度（HA）部署可能會失敗並回復。如果 Cloud Volumes ONTAP 節點和中介執行個體無法使用，放置群組的建立也會失敗，並且部署會回復。為避免這種情況，您可以修改組態，讓部署即使在放置群組建立失敗的情況下也能完成。

繞過回滾程序後， Cloud Volumes ONTAP部署程序已成功完成，並通知您放置群組建立未完成。

.步驟
. 使用 SSH 連線到NetApp Console代理主機並登入。
. 導航至 `/opt/application/netapp/cloudmanager/docker_occm/data`。
. 編輯 `app.conf`透過改變 `rollback-on-placement-group-failure`參數 `false`。此參數的預設值是 `true`。
+
[listing]
----
{
    "occm" : {
        "aws" : {
            "rollback-on-placement-group-failure" : false
        }
    }
}
----
. 儲存檔案並登出控制台代理程式。您不需要重新啟動控制台代理。

=== 針對特定 Cloud Volumes ONTAP 版本升級 ONTAP 熱修復程式的指南

ONTAP 已發布以下與 Cloud Volumes ONTAP 9.14.1、9.15.1、9.16.1、9.17.1、9.18.1 及 9.19.1 版本相容的 Hotfix：

* 9.14.1P18HF1
* 9.15.1P20HF1
* 9.16.1P16HF1
* 9.17.1P11HF1
* 9.18.1P8HF1
* 9.19.1P3HF1


如需詳細資訊，請參閱 https://security.netapp.com/advisory/ntap-20261021-0021["NTAP 安全公告 20261021-0021"^]。

對於您的 Cloud Volumes ONTAP 系統，您可能會在 NetApp Console 中收到升級至這些熱修復程式的提示。但是，這些熱修復程式僅在 Console 代理程式版本為 4.12.0 或更新版本時才受支援。如果 Console 代理程式版本早於 4.12.0，請忽略此提示。

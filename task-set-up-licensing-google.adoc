= 在 Google Cloud 中設定Cloud Volumes ONTAP許可

:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在 Google Cloud 中決定使用 Cloud Volumes ONTAP 的哪種授權選項後，在建立系統時選擇該選項之前，請先完成一些設定步驟。



[[freemium]]
== 免費增值

選擇免費加值服務，免費使用Cloud Volumes ONTAP，最高可提供 500 GiB 的設定容量。link:concept-licensing.html#packages["了解有關免費增值服務的更多信息"] 。

.步驟
. 從左側導覽功能表中，選擇“儲存”>“管理”。
. 在 *系統* 頁面上，選取 *新增系統*，然後按照 NetApp Console 中的步驟操作。
+
.. 在 *詳細資訊與憑證* 頁面上，選取 *編輯憑證 > 新增訂閱*，然後依照提示訂閱 Google Cloud Marketplace 中的隨用隨付產品。
+
除非您使用的預置容量超過 500 GiB，否則不會透過市場訂閱向您收費。如果超過，系統將自動轉換為 link:concept-licensing.html#packages["基本套餐"]。

.. 返回控制台後，到達收費方式頁面時選擇「免費增值」。
+

link:task-deploying-gcp.html["查看在 Google Cloud 中啟動Cloud Volumes ONTAP 的逐步說明"] 。



[[capacity-based-license]]
== 基於容量的許可證

以容量為基礎的授權可讓您按 TiB 容量為 Cloud Volumes ONTAP 付費。以容量為基礎的授權以 _套件_ 形式提供：Essentials 或 Professional。

Essentials 和 Professional 套餐提供以下幾種消費模式或購買選項：

* 從 NetApp 購買的授權（自備授權或 BYOL）
* Google Cloud Marketplace 的按小時付費 (PAYGO) 訂閱
* 年度合約


link:concept-licensing.html#capacity-based-licensing["了解有關基於容量的許可的更多信息"] 。

若要開始使用這些消費模式，請依照以下各節的步驟操作。



[[byol]]
=== BYOL

透過從NetApp購買授權 (BYOL) 進行預付款，以便在任何雲端供應商部署Cloud Volumes ONTAP系統。


NOTE: NetApp 已限制 BYOL 授權的購買、延期和續約。如需詳細資訊，請參閱 https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html#restricted-availability-of-byol-licensing-for-cloud-volumes-ontap["Cloud Volumes ONTAP的 BYOL 授權可用性受限"^]。

.步驟
. https://www.netapp.com/forms/sales-contact/["聯絡NetApp銷售人員以取得許可證"^]
. https://docs.netapp.com/us-en/console-setup-admin/task-adding-nss-accounts.html#add-an-nss-account["將您的NetApp支援網站帳號新增至NetApp Console"^]
+
控制台會自動查詢 NetApp 的授權服務，以取得與您的NetApp支援網站帳戶相關的授權的詳細資訊。如果沒有錯誤，控制台將新增許可證。

+
您必須先從控制台取得授權，才能與 Cloud Volumes ONTAP 一起使用。如有需要，您可以link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html#add-a-license["手動將許可證新增至控制台"]。

. 在 *系統* 頁面上，選取 *新增系統* 並依照步驟操作。
+
.. 在 *詳細資訊與憑證* 頁面上，選取 *編輯憑證 > 新增訂閱*，然後依照提示訂閱 Google Cloud Marketplace 中的隨用隨付產品。
+
您向 NetApp 購買的授權一律會優先計費，但如果您超出授權容量或授權期限到期，則會按市場的每小時費率向您收費。

.. 返回控制台後，在到達收費方式頁面時選擇基於容量的套餐。
+
image:screenshot-professional.png["建立Cloud Volumes ONTAP系統時專業選項的螢幕截圖。"]





link:task-deploying-gcp.html["查看在 Google Cloud 中啟動Cloud Volumes ONTAP 的逐步說明"] 。



[[paygo-subscription]]
=== PAYGO 訂閱

透過訂閱雲端供應商市場提供的服務按小時付費。

當您建立Cloud Volumes ONTAP系統時，控制台會提示您訂閱 Google Cloud Marketplace 中提供的協定。然後將該訂閱與系統關聯以進行收費。您可以將同一訂閱用於其他系統。

.步驟
. 從左側導覽功能表中，選擇“儲存”>“管理”。
. 在 *系統* 頁面上，選取 *新增系統* 並依照步驟操作。
+
.. 在 *詳細資訊與憑證* 頁面上，選取 *編輯憑證 > 新增訂閱*，然後依照提示訂閱 Google Cloud Marketplace 中的隨用隨付產品。
.. 返回控制台後，在到達收費方式頁面時選擇基於容量的套餐。
+
image:screenshot-professional.png["建立Cloud Volumes ONTAP系統時專業選項的螢幕截圖。"]





link:task-deploying-gcp.html["查看在 Google Cloud 中啟動Cloud Volumes ONTAP 的逐步說明"] 。


TIP: 您可以從「設定」>「憑證」頁面管理與您的帳戶相關的 Google Cloud Marketplace 訂閱。 https://docs.netapp.com/us-en/console-setup-admin/task-adding-gcp-accounts.html["了解如何管理您的 Google Cloud 憑證和訂閱"^]



[[annual-contract]]
=== 年度合約

透過購買年度合約每年支付Cloud Volumes ONTAP 的費用。

.步驟
. 聯絡您的NetApp銷售代表購買年度合約。
+
該合約在 Google Cloud Marketplace 中以私人優惠形式提供。

+
NetApp與您分享私人優惠後，您可以在系統建立期間從 Google Cloud Marketplace 訂閱時選擇年度方案。

. 在 *系統* 頁面上，選取 *新增系統* 並依照步驟操作。
+
.. 在 *詳細資訊和憑證* 頁面上，選取 *編輯憑證 > 新增訂閱*，然後依照提示在 Google Cloud Marketplace 中訂閱年度計畫。
.. 在 Google Cloud 中，選擇與您的帳戶共享的年度計劃，然後選擇 *訂閱*。
.. 返回控制台後，在到達收費方式頁面時選擇基於容量的套餐。
+
image:screenshot-professional.png["建立Cloud Volumes ONTAP系統時專業選項的螢幕截圖。"]





link:task-deploying-gcp.html["查看在 Google Cloud 中啟動Cloud Volumes ONTAP 的逐步說明"] 。



[[keystone-subscription]]
== Keystone訂閱

Keystone訂閱是一種按需付費的訂閱式服務。link:concept-licensing.html#keystone-subscription["了解有關NetApp Keystone訂閱的更多信息"] 。

.步驟
. 如果您尚未訂閱， https://www.netapp.com/forms/keystone-sales-contact/["聯絡NetApp"^]
. mailto:ng-keystone-success@netapp.com[聯絡 NetApp] 以授權您的 Console 使用者帳戶使用一個或多個 Keystone 訂閱。
. NetApp 授權您的帳戶後，link:task-manage-keystone.html["連結您的訂閱以用於Cloud Volumes ONTAP"]。
. 在 *系統* 頁面上，選取 *新增系統* 並依照步驟操作。
+
.. 當提示選擇充電方式時，選擇Keystone Subscription 充電方式。
+
image:screenshot-keystone.png["建立Cloud Volumes ONTAP系統時Keystone訂閱選項的螢幕截圖。"]

[[node-based-license]]
== 基於節點的許可證

以節點為基礎的授權是 Cloud Volumes ONTAP 的上一代授權。您可以向 NetApp （BYOL） 購買以節點為基礎的授權。目前，以節點為基礎的授權僅在特定情況下可供續約。如需詳細資訊，請參閱：

* https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html#end-of-availability-for-node-based-licenses["基於節點的許可證的可用性終止"^]
* https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html#end-of-availability-of-node-based-licenses["基於節點的許可證的可用性終止"^]
* https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-convert-node-capacity.html["將基於節點的許可證轉換為基於容量的許可證"^]
